# Build notes — One-Line Office Jokes

The entry is one single-line office joke, 89 characters, written by a small
Python program to the output entry file. The joke turns on the
passive-aggressive office email phrase "per my last email": the worker types
it, and autocorrect rewrites it as the blunt truth underneath, "as I already
told you, twice". The laugh lands in the last few words, the line needs no
setup beyond itself, and it avoids the tired meeting, reply-all and printer
angles the brief warns against.

The program holds the joke as one constant, checks it against the gate
before writing (one to 199 characters, a single line, no trailing newline),
creates the output folder when needed, and writes the file as plain text.

The repository holds the program, a readme with the three linked make.fun
badges, and an MIT licence. The entry was run locally and the output file
checked: one line, 89 characters, no trailing newline.

The bounty runs blind rounds, so nothing is judged at submit time; the
entry waits for the rounds and the final heat. The deadline is the 27th of
November 2026, and the result is due the 19th of December 2026.
